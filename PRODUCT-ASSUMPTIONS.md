# Product Assumptions — Student Skill Tracker

## 1. Product
Student Skill Tracker is a web application that helps college students organize the skills they are learning, track their progress, and manage small learning goals in one place.

## 2. Problem
College students often learn several technical and soft skills at the same time, but may not have a simple way to record what they are learning or measure their progress. Without clear goals and a visible record of improvement, it can be difficult to stay organized and motivated.

## 3. Target users
- College students learning programming, design, communication, and other career-related skills.
- Students preparing for internships, projects, placements, or personal development.
- Beginners who want a simple way to organize their learning activities.

## 4. Main use case
A student opens SkillTrack and checks their dashboard to review their current skills and progress. They add a skill they have started learning, set a small learning goal, and mark the goal as completed after practising. The dashboard updates to show their current progress.

## 5. Core features
- Dashboard showing skill count, overall progress, and completed goals.
- View a list of skills with category, level, and progress percentage.
- Add a new skill and set its current level and progress.
- Create learning goals.
- Mark goals as completed or incomplete.
- Responsive layout for desktop and mobile screens.

## 6. User assumptions
- Students want a simple interface that is easy to understand.
- Students may be learning multiple skills at the same time.
- Breaking learning into small goals may help students stay organized.
- Progress percentages provide a useful quick overview of learning.
- Users will enter and update their own skill and goal information.

These assumptions have not yet been validated with user interviews or surveys.

## 7. MVP scope
- A landing page introducing the product.
- A dashboard with sample progress statistics.
- A skills page that displays sample skills and allows users to add a skill.
- A goals page that allows users to create goals and mark them complete.
- React Context API to share skills, goals, and progress between pages.
- Realistic dummy data instead of a backend.
- Reusable React components and responsive styling.

## 8. Out of scope
- User registration, login, and authentication.
- Backend or database integration.
- Saving user data permanently after refreshing the page.
- AI-generated learning plans or personalized recommendations.
- Social features, leaderboards, and sharing progress with friends.
- Notifications, reminders, and calendar integration.
- Integration with external learning platforms.
