# SkillTrack Design System

## Colors
- Primary / highlight: `#D9F36A`
- Secondary: `#7D8B65`
- Background: `#FBFBF8`
- Surface: `#FFFFFF`
- Main text: `#20221F`
- Muted text: `#858980`
- Border: `#E9EAE4`
- Success: `#4C9863`
- Error: `#B94A48`

## Typography
- Display and headings: Manrope, fallback sans-serif
- Body and controls: DM Sans, fallback sans-serif
- H1: 34–72px, extra bold depending on viewport
- H2: 16–34px, bold
- Body: 14px
- Supporting text: 10–12px

## Reusable components
- Brand mark and navigation
- Sidebar navigation
- Button
- Stat card
- Skill card and progress bar
- Goal checkbox row
- Form input and select
- Notice message
- Empty/feedback state

## UI principles
- Keep layouts spacious and readable.
- Use the lime accent only for key actions and progress.
- Use neutral surfaces and subtle borders.
- Keep navigation consistent across dashboard pages.
- Support mobile layouts with responsive CSS.
